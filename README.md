# 🤖 Small Hammer ROS2

ROS 2 description, control, and simulation package for the Small Hammer 6-DOF robotic arm.

## Planned Features

- URDF/Xacro robot description
- RViz visualization
- ESP32 hardware interface
- MoveIt 2 integration
- NVIDIA Isaac Sim support
- Digital Twin

## Hardware

- Small Hammer 6-DOF Robot Arm
- MG996R Servos
- ESP32 Controller
